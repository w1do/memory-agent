# compatibility

Совместимость версий формата, схем и алгоритма ID.

## Требования

### Требование: версия формата в манифесте

Манифест SHALL содержать `formatVersion=1`, версии приложения, SQLite-схемы и алгоритма ID. Импорт SHALL принимать только поддерживаемые версии.

Сценарий: поддерживаемая версия
- Given `formatVersion=1` и поддерживаемые версии схем
- When выполняется `memory import <name>`
- Then проверка совместимости проходит

Сценарий: будущая версия
- Given `formatVersion` больше поддерживаемого
- When выполняется `memory import <name>`
- Then импорт отказывает с указанием поддерживаемой версии
- And активная память не изменяется

### Требование: fingerprint embedding полный

Embedding fingerprint SHALL включать модель, неизменяемую ревизию или идентификатор весов, dimensions, обработку входа, усечение, нормализацию и distance. Fingerprint SHALL браться из происхождения сохранённых векторов, а не из текущей конфигурации.

Сценарий: поля fingerprint
- Given дамп создан
- When читается манифест
- Then все перечисленные поля fingerprint присутствуют

### Требование: версионированный алгоритм ID

Параметры построения ID, включая ordinal одинаковых чанков, SHALL быть записаны в манифест. Пересчёт ID при импорте SHALL выполняться по этому алгоритму.

Сценарий: одинаковые чанки
- Given в файле несколько чанков с одинаковым содержимым
- When выполняется dump и затем import
- Then ordinal каждого чанка сохраняется
- And множество ID после импорта совпадает с множеством до переноса после обратного отображения

### Требование: гарантия содержимого

После импорта все векторы SHALL перечитываться и сверяться с экспортом. Допуск SHALL быть абсолютным `1e-6` для float32. Побитовая идентичность внутреннего хранения Qdrant SHALL NOT требоваться.

Сценарий: проверка векторов
- Given импорт собрал новое поколение
- When проверяются векторы
- Then dimensions совпадают, значения конечны и отличие от экспорта не больше `1e-6`

Сценарий: проверка содержимого
- Given импорт собран
- When проверяются SQLite integrity, связи, счётчики и полные множества ID
- Then все проверки проходят до публикации

### Требование: границы гарантии

Гарантия SHALL относиться к содержимому снимка с заменёнными локальными привязками. Содержимое рабочего дерева и порядок поисковой выдачи SHALL NOT входить в гарантию.

## Не проверено

- Набор поддерживаемых версий сервисов (Qdrant, Typesense) и SQLite-схем: не определён.
- Фактическое отличие нормализованных Cosine-векторов от экспорта: не измерено.
- Совместимость с будущими версиями `formatVersion`: не определена.
