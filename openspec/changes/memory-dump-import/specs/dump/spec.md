# dump

Создание переносимого дампа памяти проекта командой `memory dump <name>`.

## Требования

### Требование: dump создаёт полный согласованный снимок

`memory dump <name>` SHALL создать `./memory/<name>/` со всеми артефактами формата из `design.md`, раздел 3, только из согласованного состояния памяти.

Сценарий: успешный dump
- Given память проекта согласована: нет pending embeddings и незавершённых изменений, множества `chunkId` в SQLite, Qdrant и Typesense совпадают
- When выполняется `memory dump <name>`
- Then создаются `manifest.json` и все перечисленные артефакты
- And контрольные суммы артефактов совпадают с записями манифеста
- And `dumpId` равен SHA-256 канонического манифеста без поля `dumpId`

Сценарий: существующий каталог
- Given `./memory/<name>/` уже существует
- When выполняется `memory dump <name>`
- Then команда завершается ошибкой
- And существующий каталог не изменяется

### Требование: dump отказывает при несогласованном источнике

`memory dump` SHALL отказать, если состояние памяти несогласованно. Автоматического исправления и вычисления embeddings SHALL NOT выполняться.

Сценарий: несовпадение числа точек
- Given в Qdrant меньше точек, чем чанков в SQLite
- When выполняется `memory dump <name>`
- Then команда завершается ошибкой с перечнем расхождений
- And каталог `./memory/<name>/` не создаётся

Сценарий: pending embeddings
- Given есть чанки с pending embeddings
- When выполняется `memory dump <name>`
- Then команда завершается ошибкой
- And embedding не вычисляется

Сценарий: смешанное происхождение векторов
- Given происхождение сохранённых векторов неизвестно или смешано
- When выполняется `memory dump <name>`
- Then команда завершается ошибкой
- And fingerprint берётся не из текущей конфигурации

### Требование: запрещённые данные не попадают в дамп

Дамп SHALL NOT содержать `.env*`, `global.env`, ключи, credentials, локальные конфиги сервисов, кэши, Docker volumes, логи и историю задач. `memory/` SHALL исключаться из индексации независимо от Git.

Сценарий: запрещённый файл не в индексе
- Given запрещённые файлы не представлены в индексе
- When выполняется `memory dump <name>`
- Then в артефактах дампа нет их содержимого и путей

Сценарий: запрещённый файл уже в индексе
- Given запрещённый файл представлен в `index.db`, Qdrant или Typesense
- When выполняется `memory dump <name>`
- Then команда завершается ошибкой с указанием, что нужно очистить индекс
- And дамп не создаётся
- And исключение файла только при упаковке не выполняется

Сценарий: каталог дампа не индексируется
- Given `./memory/<name>/` существует внутри проекта
- When выполняется индексация
- Then содержимое `memory/` не попадает в индекс

### Требование: имя дампа безопасно

`<name>` SHALL быть одним компонентом пути. Абсолютные пути, `..` и выход через symlink SHALL быть отклонены.

Сценарий: попытка выйти из `memory/`
- Given `<name>` равен `../x` или `/tmp/x`
- When выполняется `memory dump <name>`
- Then команда завершается ошибкой
- And файлы вне `./memory/` не создаются

### Требование: dump атомарен

Запись SHALL выполняться во временный каталог. Переименование в `./memory/<name>/` SHALL выполняться только после всех проверок.

Сценарий: сбой во время записи
- Given dump прерван до переименования
- When команда завершена с ошибкой
- Then `./memory/<name>/` не существует
- And временный каталог удалён или помечен как незавершённый

## Не проверено

- Механизм общей блокировки записей между процессами: не проверено.
- Точный состав полей, переносимых из SQLite: задан решением Sol по смыслу, полный список не выписан.
