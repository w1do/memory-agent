# Задачи: `memory dump` и `memory import`

Отметка `[x]` ставится только после реализации и успешной проверки этапа.

Порядок: M1 → M2 → M3 → M4 → M5. Команды проверки предложены по образцу `init-timeout` (`npm test -- <файл>`), имена тестовых файлов не подтверждены и уточняются при реализации.

## M1. Формат и манифест

- [x] Схема `manifest.json` с `formatVersion=1`, версиями и параметрами коллекций.
- [x] `dumpId` вычисляется как SHA-256 канонического манифеста без `dumpId`.
- [x] Контрольные суммы артефактов и индексированных файлов записаны в манифест.
- [x] Каноническая сериализация детерминирована: один и тот же вход даёт тот же `dumpId`.

Проверено: 6 тестов `dump-manifest.test.ts`, exit 0; `npx tsc --noEmit`, exit 0.

Проверка: `npm test -- test/unit/dump-manifest.test.ts`

## M2. `memory dump <name>`

- [ ] Создаётся `./memory/<name>/` с полным набором артефактов из `design.md`.
- [ ] Запись во временный каталог, атомарное переименование после проверок.
- [ ] Отказ при несогласованном источнике (pending embeddings, расхождение `chunkId`, лишние или недостающие точки).
- [ ] Отказ, если `./memory/<name>/` уже существует.
- [ ] Отказ, если запрещённые файлы представлены в индексе.
- [ ] Запрещённые файлы не попадают в артефакты.
- [ ] `<name>` с `..`, абсолютным путём или выходом через symlink отклоняется.
- [ ] `memory/` исключается из индексации.
- [ ] Общая блокировка записей на время снимка (механизм не проверен).

Проверка: `npm test -- test/unit/memory-dump.test.ts`

## M3. `memory import <name>`: проверки до изменения памяти

- [x] Проверка SHA-256 артефактов и размеров до изменения активной памяти.
- [x] Неподдерживаемый `formatVersion` и версии схем отклоняются понятной ошибкой.
- [x] Несовпадение модели, ревизии, обработки входа или dimensions отклоняется; ошибка показывает обе конфигурации.
- [x] Одинаковые dimensions при разной модели не считаются совместимыми.
- [x] Неизвестное значение fingerprint отклоняется.
- [x] Embedding при импорте не вычисляется.
- [x] `global.env` не изменяется.

Проверено: 43 теста `memory-import-checks.test.ts`, exit 0; `npx tsc --noEmit`, exit 0.

Проверка: `npm test -- test/unit/memory-import-checks.test.ts`

## M4. `memory import <name>`: перепривязка и поколения

- [x] `projectId` получателя сохраняется, либо выдаётся новый по его root; `sourceProjectId` сохраняется как provenance.
- [x] `projects.root` и абсолютные `files.path` переписаны.
- [x] `fileId`, `chunkId` и UUID точек пересчитаны по версионированному алгоритму; карта соответствий полная.
- [x] Векторы перенесены без embedding.
- [x] Совпавшие по SHA-256 файлы получают локальный mtime; несовпавшие и отсутствующие помечаются `stale`; лишние — `unindexed`.
- [x] Аннотации stale-файлов помечаются неактуальными.
- [x] `sync` не запускается автоматически.
- [x] Новое поколение собирается отдельно и публикуется одним атомарным переключением.
- [x] Старое поколение сохраняется для отката.
- [x] Журнал операции позволяет довести переключение или убрать staging после сбоя.
- [x] Повторный импорт того же `dumpId` не создаёт дубликатов; после локальных изменений заменяет память.

Проверено: 25 тестов `memory-import-generation.test.ts`, exit 0; `npx tsc --noEmit`, exit 0.

Проверка: `npm test -- test/unit/memory-import-generation.test.ts`

## M5. Гарантия «то же самое» и документация

- [x] SQLite integrity, связи, счётчики и полные множества ID совпадают после обратного отображения ID.
- [x] Тексты, payload и аннотации совпадают с дампом.
- [x] Все векторы перечитаны: dimensions, конечность значений, отличие от экспорта не больше `1e-6`.
- [x] Round-trip тест: dump → import на чистом проекте → сравнение с источником по логическим хешам.
- [x] Документация команд и формата: `memory/` в `.gitignore`, передача архивом или LFS.

Проверено: 24 теста `memory-roundtrip.test.ts`, exit 0; `npx tsc --noEmit`, exit 0.
SQLite и файловая система настоящие, Qdrant/Typesense заменены внешними in-memory адаптерами; все проекты во временных каталогах.

Проверка: `npm test -- test/unit/memory-roundtrip.test.ts`

Полный прогон: `npm test`, exit 1 — BLOCKED в sandbox: `listen EPERM: operation not permitted 127.0.0.1` в 14 тестах (`env.test.ts`, `shared-init.test.ts`); остальные 227 тестов прошли.
